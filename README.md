# 🛍️ Bagbabes - Premium E-Commerce Platform

> A fully functional, production-ready e-commerce web application built with React, Firebase, and Cloudinary. Designed for bag and accessory retailers.

[https://bagbabes.com.ng]

---

## 📖 Overview

Bagbabes is a complete e-commerce solution that enables businesses to sell products online with ease. It features a modern, responsive design, real-time inventory management, WhatsApp integration for order confirmations, and an intuitive admin dashboard.

---

## ✨ Features

### 🛒 Customer Features
- **Product Catalog** - Browse products with category filtering and search
- **Smart Cart** - Persistent cart with localStorage, quantity management
- **Checkout** - Secure checkout with bank transfer payment method
- **Order Tracking** - Real-time order status updates
- **WhatsApp Integration** - Automatic order confirmation via WhatsApp
- **Responsive Design** - Mobile-first design (5 columns desktop, 2 columns mobile)

### 👑 Admin Features
- **Multi-Admin Support** - Multiple admins from .env configuration
- **Order Management** - Real-time order tracking, status updates (Pending → Processing → Shipped)
- **Product Management** - Full CRUD with automatic image compression
- **Inventory Control** - Mark products as New, Best Seller, or Out of Stock
- **Sales Analytics** - Revenue charts, top products, daily/weekly sales tracking
- **Password Management** - Secure admin password change

### 🖼️ Media & Assets
- **Cloudinary Integration** - Automatic image compression and optimization
- **Lazy Loading** - Images load only when visible in viewport
- **Best Seller Section** - Dynamic display of top products
- **New Arrival Badge** - Auto-removes after 7 days
